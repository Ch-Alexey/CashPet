# Ярик · Правки по дорожной карте и JSON

2026-09-24 · По итогам разбора с Лехой. Решения записаны в разделе 22 [рамок](../../requirements/ЛЦТ-2026-задача-6-рамки-проекта.md), числа и формулы — в [экономике](../02-экономика.md), экраны — в [функционале](../01-функционал.md).

Большая часть карты принята: онбординг, 26 заданий, магазин, копилка, соседи и мошенники — отличная работа. Ниже только то, что нужно поменять.

## Где править

- **Сегодня:** тексты правь прямо в JSON (`content/src/main/resources/content/`). Карта [05-дорожная-карта-контента](../05-дорожная-карта-контента.md) дальше — архив и черновик для заданий после 29.09; дублировать в ней правки не нужно.
- **С 25.09:** Леха и Виталик утвердят формат JSON (контракт). Тогда перенесёшь 7 заданий MVP и остальные файлы в него. Структуру JSON до этого не переделывай — только тексты и числа.

## 1. Решения, которые меняют карту

| # | Что было | Что теперь |
| --- | --- | --- |
| 1 | Разделы открываются после модулей (План после 1, Копилка после 2, Итоги после 4) | Все разделы открыты сразу. Твои пузырьки остаются — показываются при первом открытии. «Рекомендация от питомца» пройти задание — тоже остаётся |
| 2 | Показатели падают после каждого модуля | Падают в конце недели, по твоим коэффициентам и с минимумом 25 |
| 3 | «Уют» | **«Уход»** — везде в текстах и в `shop.json` |
| 4 | GP с компонентом T, 4 стадии | GP = 40·N + 30·M + 30·S, стадии **Малыш → Подросток → Взрослый** (150 / 350). Стадия «Ребёнок» исчезает |
| 5 | Звёзды знаний, k, статусы, счётчик дней | После 29.09. В наградах заданий MVP — только монеты: убрать «+{30 * k} звёзд знаний» и «+10 звёзд знаний» в задании 0 |
| 6 | День / неделя / месяц вперемешку | Везде **неделя**. «Каждый день тебе решать» → «Каждую неделю тебе решать». Раздел «Итоги месяца» — после 29.09 |
| 7 | Старт 20 монет, доход 100, рост цен со стадией | Старт 100, карманные 60, цены постоянные (см. экономику). `onboarding.json` → `starting_balances`: 100 монет, без XP. Задание 0 даёт 20 монет |
| 8 | «Подарить» как часть плана (модуль 8, общие диалоги) | Подарок — покупка из «Хочу» во время события. Убрать строку «Категория „Подарить“ пуста»; в `glossary.json` термин «Подарок»: «Покупка для друга. Идёт из „Хочу“» |
| 9 | 7.6: исход 50 на 50 | Всегда исход Б: писал не друг. Флаг `random_outcome` убрать |
| 10 | Лежанка: уют +10, куртка: уют +5 | Желаемое поднимает только настроение: уход 0 у обеих |
| 11 | 3.1 шаг 1: цели «площадка 180», «море 250» | Цель выбирается по-настоящему — показывать настоящий каталог: Когтеточка 60, Домик 100, Велосипед 150 |

## 2. Арифметика

Правило: числа кратны 5; деление — только в «посложнее» и нацело.

| Задание | Сейчас | Как исправить |
| --- | --- | --- |
| 4.1 | Пачки 20 / 48 / 90 на 1 / 3 / 6 порций, порция 16 | Пачки 20 / 30 / 40 на 1 / 2 / 4 порции (порция 20 / 15 / 10). Задание — только «посложнее» |
| 6.2 (MVP) | 20 за час / 30 за 3 часа / 45 за 5 часов, «20 против 9» | «Попроще» — сложением: «За три часа первым способом: 20 + 20 + 20 = 60, а вторым — 30». Третий вариант: 50 за 5 часов (10 в час) |
| 8.2 | 60 на 4 друзей | После 29.09, только «посложнее» |
