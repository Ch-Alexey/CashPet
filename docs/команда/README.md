# Команда CashPet · Кто за что отвечает

Каждый владеет своей зоной: решает в ней сам и отвечает за результат. В чужую зону — только через PR с ревью владельца.

| Кто | Зона | Инструкция |
| --- | --- | --- |
| Леха | Каркас, контракты, ядро экономики, CI, ревью, сдача | [леха.md](леха.md) |
| Виталик | Данные, код загрузки контента, ViewModel, демо-режим, раздел взрослого | [виталик.md](виталик.md) |
| Саня | Весь интерфейс и вся графика | [саня.md](саня.md) |
| Ярик | Контент, баланс, имена, помощь с графикой, проверка, материалы сдачи | [ярик.md](ярик.md) |

## Кто кому помогает

```
            контракты, ревью ядра
   Леха ─────────────────────────► Виталик, Саня, Ярик
     ▲                                   
     │ баги ядра                          
   Виталик ── ViewModel, UiState ──► Саня
     ▲    ── ревью JSON, тесты-сторожа ─► Ярик
     │
   Ярик ── описания, список графики, ассеты, простые предметы ──► Саня
        ── тексты заданий, числа баланса ──► Леха, Виталик
   Саня ── макеты экранов ──► Виталик (какие данные нужны экрану)
```

## Общие правила

- **Застрял больше чем на 2 часа — пиши в чат.** Сначала владельцу зоны, где проблема, потом Лехе.
- **Контракты** (модели `core`, формат JSON, `UiState`) после 20.09 меняются только с ревью Лехи.
- **Всё через PR** в `main`: ветка `имя/задача`, зелёный CI, одно одобрение.
- **Вечером — одна строка в чат:** что сделал, что дальше, что мешает.
- **Решения по продукту** записаны в разделе 22 [рамок](../../requirements/ЛЦТ-2026-задача-6-рамки-проекта.md). Хочешь поменять — сначала обсуждаем в чате, потом правим документ, потом код.
