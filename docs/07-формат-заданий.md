## Поля задания

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `id` | да | Уникальный, как в карте: `"0"`, `"1.1"` |
| `module` | да | Номер модуля карты, для группировки в прогрессе |
| `title` | да | Название в списке заданий |
| `topic` | да | `budget`, `savings`, `purchases`; после 29.09 — `safety`, `holidays`. У задания 0 — `intro` |
| `competence` | да, кроме `intro` | Номер компетенции 1–6 из раздела 1 ТЗ. Из него собирается карта образовательного контента |
| `unlock_week` | да | С какой недели задание открыто. В демо игнорируется: открыты все |
| `reward.coins` | да | Монеты за первое прохождение, не зависят от выбора |
| `neighbor_lines` | нет | `character` — ключ из `neighbors.json` (`toroplivy`, `ostorozhny`, …), не имя |
| `intro` | нет | Текст перед первым шагом |
| `steps` | да | Шаги по порядку, к 29.09 — только `template: "choice"` |
| `hard_variant` | нет | Замены для «посложнее»: по `id` шага и варианта, только поля `situation`, `label`, `effects`, `consequence`, `feedback` |

## Поля шага и варианта

| Поле | Обязательно | Что это |
| --- | --- | --- |
| `step.id` | да | Уникальный внутри задания |
| `step.template` | да | `choice` |
| `step.wallet` | нет | Учебный кошелёк шага. Настоящий баланс и план не трогает |
| `step.situation` | да | Ситуация: 2–3 коротких предложения |
| `option.id`, `option.label` | да | Текст кнопки |
| `option.effects` | да, кроме `blocked` | Последствие в числах: ключи `wallet`, `savings`, `satiety`, `care`, `mood`. Интерфейс показывает их строками «Кошелёк −30», «Настроение +15» |
| `option.consequence` | нет | Одна фраза, что произошло |
| `option.feedback` | да | Разбор, для любого варианта |
| `option.outcome` | да, кроме `blocked` | `good` — удачно; `ok` — частично; `retry` — неудачно, показываем «Попробовать иначе». Ребёнку не показывается как «верно / неверно» |
| `option.recovery` | да при `ok` и `retry` | Путь восстановления: что можно сделать дальше |
| `option.blocked`, `option.followup` | нет | Вариант-заглушка: не засчитывается, ведёт в диалог `followup` с кнопками |

Все кнопки и подписи — отдельными полями (`label`, `buttons`), не внутри текста.

## Подстановки

Только из списка. Значения считает код, в тексте — только имя.

| Подстановка | Что | Откуда |
| --- | --- | --- |
| `{playerName}` | Игровое имя ребёнка | Профиль |
| `{petName}` | Имя кота, только в именительном падеже | Профиль |
| `{goal}` | Название текущей цели | Копилка |
| `{cost}` | Стоимость цели | Копилка |
| `{saved}` | Сколько накоплено | Копилка |
| `{left}` | Сколько осталось до цели | Копилка |
| `{weeks}` | Срок сейчас, недель | Копилка |
| `{weeksAfter}` | Срок после действия, недель | Предпросмотр снятия |
| `{amount}` | Сумма действия | Действие |
| `{needMin}` | Сколько коту нужно на неделю | Конфиг экономики |

Сейчас в JSON есть ещё `{имя}` → `{playerName}`, `{60 − сумма}` → `{left}`, `{n+1}` → `{weeksAfter}`, `{ΣP − 100}` → `{amount}`, `{x}` → `{saved}`, `{n}` → `{weeks}`. Остальные (`{a}`, `{b}`, `{дело1}` и т. п.) — в заданиях после 29.09, решим при переносе.

## Что убираем из черновика

`base_xp`, `k`, `reward_repeat_formula`, `star`, `mvp`, `difficulty`, `scoring`, `scoring_note`, `random_outcome`. XP и звёзды знаний вернутся после 29.09 отдельным полем. Поле `difficulty` (easy/medium/hard) путалось со сложностью профиля «попроще / посложнее».

## Тесты-сторожа

Загрузчик контента проверяет при каждой сборке, CI красный — в логе правило и `id` задания:

- JSON читается, `id` заданий, шагов и вариантов уникальны.
- Не меньше 6 заданий с темой, по каждой из трёх тем — не меньше 2.
- В шаге 2–3 варианта без `blocked`; хотя бы один `good`; у `blocked` есть `followup`.
- У каждого варианта есть `feedback`; при `ok` и `retry` — `recovery`.
- `reward.coins` > 0; все суммы в `reward`, `wallet`, `effects` кратны 5 и не больше 999 по модулю.
- Учебный кошелёк не уходит в минус: `wallet` + `effects.wallet` ≥ 0.
- `competence` от 1 до 6, `topic` из списка, `character` есть в `neighbors.json`.
- `hard_variant` ссылается только на существующие шаги и варианты.
- Подстановки — только из списка выше, без выражений.
- Тексты: предложение не длиннее 12 слов; числа перед словом «монет» кратны 5; в `feedback` вариантов `retry` нет «!».
- Падеж имени: нет `у {petName}`, `о {petName}`, `с {petName}`, `к {petName}`, нет глагола прошедшего времени сразу после `{petName}`. Проверка приблизительная, ловит основные ошибки.
