# CashPet · Окружение разработки

2026-09-29 · Что установить, чтобы собрать и запустить проект на Windows или Mac. Всё бесплатно.

## Общее для всех

| Что | Зачем | Windows | Mac |
| --- | --- | --- | --- |
| **Git** | Версии кода | [git-scm.com](https://git-scm.com/download/win) → Git for Windows | Уже есть (`git --version`), иначе `xcode-select --install` |
| **GitHub Desktop** | Git без командной строки — для тех, кто им не пользовался | [desktop.github.com](https://desktop.github.com) | то же, или `brew install --cask github` |
| **Android Studio** | Редактор, JDK (JBR — идёт вместе со Studio, отдельно Java не ставим), Android SDK, эмулятор, `adb` — всё в одном | [developer.android.com/studio](https://developer.android.com/studio) | то же, или `brew install --cask android-studio` |
| **Аккаунт GitHub** | Только для участия в разработке; чтобы собрать проект, достаточно `git clone https://github.com/Ch-Alexey/CashPet` | — | — |

Проект собирается одинаково на Mac и Windows. Разные окончания строк выравнивает `.gitattributes` в корне — ничего настраивать не нужно.

Kotlin и Gradle отдельно **не ставим** — их скачает сам проект через Gradle Wrapper.

### Первый запуск Android Studio

В мастере установки выбрать Standard. Потом **Settings → Languages & Frameworks → Android SDK** и отметить:

- SDK Platforms: последний стабильный Android и **Android 8.0 (API 26)** — для проверки минимальной версии.
- SDK Tools: Android SDK Build-Tools, Platform-Tools, Emulator.

Эмулятор (**Device Manager → Create device**): профиль **Small Phone** — 720 × 1280 при xhdpi, ровно 360 dp шириной. У всех Pixel ширина от 393 dp, для проверки 360 dp они не подходят. Образ — **API 26 "Oreo"; Android 8.0**, вариант **Google APIs**: в фильтре Services выбрать «Google APIs», иначе мастер показывает только образы Google Play. На Windows — образ x86_64 (не x86), на Mac с Apple Silicon — arm64. Для повседневной работы удобно завести второй Small Phone на свежем API.

Проверка ширины на запущенном эмуляторе: `adb shell wm size` и `adb shell wm density`, ширина в dp = пиксели × 160 ÷ density.

### Переменные окружения (чтобы `./gradlew` и `adb` работали из терминала)

**Mac** — добавить в `~/.zshrc`:

```bash
printf '%s\n' 'export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"' 'export ANDROID_HOME="$HOME/Library/Android/sdk"' 'export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"' >> ~/.zshrc
```

**Windows** — Пуск → «Изменить системные переменные среды» → Переменные среды:

- `JAVA_HOME` = `C:\Program Files\Android\Android Studio\jbr`
- `ANDROID_HOME` = `%LOCALAPPDATA%\Android\Sdk`
- в `Path` добавить `%ANDROID_HOME%\platform-tools`

Проверка в новом терминале: `java -version` и `adb version`.

### Телефон

1. Настройки → О телефоне → 7 раз нажать на «Версия ПО» — включатся «Для разработчиков».
2. В «Для разработчиков» включить **Отладку по USB**; на Xiaomi — ещё **Установку через USB**.
3. Подключить кабелем, на телефоне разрешить отладку. `adb devices` должен показать устройство.
4. **Windows:** если телефон не виден — поставить USB-драйвер телефона с сайта производителя. На Mac драйвер не нужен.

Тестовый телефон — Xiaomi 24116RACCG, Android 16, 12 ГБ ОЗУ. На Xiaomi, кроме отладки по USB, нужно включить **«Установка через USB»** (HyperOS может попросить Mi-аккаунт и SIM-карту) и подтверждать установку на экране телефона.

## Сборка и проверка

- **Сборка и тесты:** `./gradlew test assembleDebug` (Windows — `gradlew.bat`), APK — в `app/build/outputs/apk/debug/`. Если Gradle не находит SDK — `local.properties` по образцу `local.properties.example` или переменная `ANDROID_HOME`.
- **Поставить на телефон:** `./gradlew installDebug`.
- **Симулятор экономики:** `./gradlew :content:simulate` — таблицы трёх сценариев по настоящим JSON и проверки неравенств, итог — в `content/build/simulate.md`.
- **База Room на устройстве:** Android Studio → App Inspection → Database Inspector.
- **Экран телефона на компьютере и запись видео:** [scrcpy](https://github.com/Genymobile/scrcpy) (`brew install scrcpy` на Mac).
- Эмулятор — для проверки Android 8.0 (API 26) и ширины 360 dp; основная проверка — на телефоне.

## Графика

- **Figma** или **Inkscape** — векторная обводка котов и значков.
- SVG в проект: Android Studio → File → New → Vector Asset → Local file.
- ИИ-эскизы — только с записью в `design/ai-log.md` (сервис, запрос, условия использования).
