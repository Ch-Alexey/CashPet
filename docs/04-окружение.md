В команде Mac (Леха, Саня) и Windows (Виталик, Ярик). Разные окончания строк выравнивает `.gitattributes` в корне — ничего настраивать не нужно.

Kotlin и Gradle отдельно **не ставим** — их скачает сам проект через Gradle Wrapper.

### Первый запуск Android Studio

В мастере установки выбрать Standard. Потом **Settings → Languages & Frameworks → Android SDK** и отметить:

- SDK Platforms: последний стабильный Android и **Android 8.0 (API 26)** — для проверки минимальной версии.
- SDK Tools: Android SDK Build-Tools, Platform-Tools, Emulator.

Эмулятор (**Device Manager → Create device**): профиль **Small Phone** — 720 × 1280 при xhdpi, ровно 360 dp шириной. У всех Pixel ширина от 393 dp, для проверки 360 dp они не подходят. Образ — **API 26 "Oreo"; Android 8.0**, вариант **Google APIs**: в фильтре Services выбрать «Google APIs», иначе мастер показывает только образы Google Play. На Windows — образ x86_64 (не x86), на Mac с Apple Silicon — arm64. Для повседневной работы удобно завести второй Small Phone на свежем API.

Проверка ширины на запущенном эмуляторе: `adb shell wm size` и `adb shell wm density`, ширина в dp = пиксели × 160 ÷ density.

### Переменные окружения (чтобы `./gradlew` и `adb` работали из терминала)

**Mac** — добавить в `~/.zshrc`:

```bash
printf '%s\n' 'export JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"' 'export ANDROID_HOME="$HOME/Library/Android/sdk"' 'export PATH="$ANDROID_HOME/platform-tools:$ANDROID_HOME/emulator:$PATH"' >> ~/.zshrc
```

**Windows** — Пуск → «Изменить системные переменные среды» → Переменные среды:

- `JAVA_HOME` = `C:\Program Files\Android\Android Studio\jbr`
- `ANDROID_HOME` = `%LOCALAPPDATA%\Android\Sdk`
- в `Path` добавить `%ANDROID_HOME%\platform-tools`

Проверка в новом терминале: `java -version` и `adb version`.

### Телефон

1. Настройки → О телефоне → 7 раз нажать на «Версия ПО» — включатся «Для разработчиков».
2. В «Для разработчиков» включить **Отладку по USB**; на Xiaomi и vivo — ещё **Установку через USB**.
3. Подключить кабелем, на телефоне разрешить отладку. `adb devices` должен показать устройство.
4. **Windows:** если телефон не виден — поставить USB-драйвер vivo с сайта производителя. На Mac драйвер не нужен.

Тестовый телефон — Xiaomi 24116RACCG, Android 16, 12 ГБ ОЗУ. На Xiaomi, кроме отладки по USB, нужно включить **«Установка через USB»** (HyperOS может попросить Mi-аккаунт и SIM-карту) и подтверждать установку на экране телефона.

## По ролям

### Леха (Mac)

- Всё общее.
- **Claude Code:** `curl -fsSL https://claude.ai/install.sh | bash`, затем `claude` в папке проекта.
- **GitHub CLI** для настройки защиты веток и CI: `brew install gh`.
- **scrcpy** — экран телефона на маке и запись видео: `brew install scrcpy`.

На Mac 8 ГБ ОЗУ: Android Studio с эмулятором работают на пределе. Основную проверку — на телефоне, эмулятор — только для API 26 и ширины 360 dp.

### Виталик (Windows)

- Всё общее.
- **Claude Code:**
  PowerShell: `irm https://claude.ai/install.ps1 | iex` — нужен установленный Git for Windows.
- База Room смотрится прямо в Android Studio: **App Inspection → Database Inspector**, отдельная программа не нужна.

### Саня (Mac)

- Всё общее.
- **Figma** — макеты и векторная обводка котов: [figma.com](https://www.figma.com) (в браузере или приложение), бесплатный план.
- **Inkscape** — если удобнее рисовать вектор не в Figma: [inkscape.org](https://inkscape.org) или `brew install --cask inkscape`.
- **Генератор изображений** для эскизов — выбрать один сервис до 19.09, прочитать условия использования, завести `design/ai-log.md`.
- **scrcpy** — экран телефона на маке, удобно проверять анимации: `brew install scrcpy`.
- SVG в проект: Android Studio → **File → New → Vector Asset → Local file**.

### Ярик (Windows)

- Всё общее. Android Studio нужна, чтобы открыть проект и запускать симулятор баланса одной командой (`gradlew :content:simulate` в терминале Android Studio) и тесты; JSON тоже удобно править в ней.
- **Симулятор баланса** — `gradlew :content:simulate` в терминале Android Studio: таблицы трёх сценариев по настоящим JSON, итог ещё и в `content/build/simulate.md`. Python больше не нужен.
- **Презентация и карточка RuStore** (после 29.09): PowerPoint, либо бесплатный LibreOffice Impress, либо Google Slides. Шрифт **Montserrat** (OFL) с [fonts.google.com](https://fonts.google.com/specimen/Montserrat) — установить в систему, иначе шаблон отобразится неправильно.
