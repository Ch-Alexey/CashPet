# CashPet · Функционал и пользовательский путь

2026-09-18 · Источник решений — раздел 22 [рамок проекта](../requirements/ЛЦТ-2026-задача-6-рамки-проекта.md). Числа — в [экономике](02-экономика.md).

Игра прежде всего про навыки: учебные задания по темам ТЗ — ядро, остальное (кот, магазин, копилка) показывает последствия решений.

## Карта экранов

```
Старт ─┬─ [Играть] ─► Онбординг (3–4 слайда) ─► Игровое имя ─► Выбор кота 3×3 ─► Имя кота ─► Сложность ─► Первый период
       └─ [Для взрослых] ─► барьер ─► Раздел взрослого (в т.ч. «Запустить демо»)

                 ┌───────────────── ДОМ (экран с котом) ─────────────────┐
 Верхняя панель: │ ⚙  │ 💰 баланс │ 🐷 копилка · цель · полоска │ 📈 прогресс │
 Центр:          │           кот + 🍗 Сытость · 🧼 Уход · 😊 Настроение    │
 Над меню:       │           [Задание: …] — быстрый переход               │
 Нижнее меню:    │   Дом · План · Магазин · Копилка · Задания             │
                 └────────────────────────────────────────────────────────┘
 Кнопка «Завершить период» ─► подтверждение ─► Итог периода ─► Новый период ─► План
```

Шесть обязательных элементов главного экрана по п. 2.5.3: кот, баланс, накопления, текущая цель, показатели состояния, активное задание. Все видны без прокрутки при ширине 360 dp.

## 1. Первый запуск

| Шаг | Экран | Что происходит |
| --- | --- | --- |
| 1 | Старт | «Играть» и неприметная ссылка «Для взрослых» |
| 2 | Онбординг | Котляндия; три типа решений — нужное, желаемое, отложить; как устроен период. Можно пролистать |
| 3 | Игровое имя | Одно поле: «Придумай имя для игры, не настоящее». Ни возраста, ни контактов |
| 4 | Выбор кота | Сетка 3 × 3: 3 кота × 3 окраса, анимированные, стадия 1 |
| 5 | Имя кота | Ввод имени, приветственная анимация |
| 6 | Сложность | «Попроще / посложнее». Потом меняется только в разделе взрослого со сбросом |
| 7 | Первый период | Стартовый бюджет, выбор цели, первое задание |

Кнопка «?» на каждом экране открывает подсказку к нему — возврат к подсказке в любой момент (п. 2.5.1).

## 2. Профили

- Один профиль ребёнка.
- Отдельный демо-профиль: демо-режим не трогает игру ребёнка.
- «Изменить внешность кота» в настройках: кот и окрас меняются в любой момент, прогресс сохраняется. Это «повторная настройка» из таблицы 2.6 ТЗ.
- Всё сохраняется автоматически после каждого действия (Room). Повторный запуск открывает ровно то же место.

## 3. Кот

- **Внешность:** 3 кота разного силуэта × 3 окраса. Окрас — цвет плюс узор (полоски, пятна, однотонный), чтобы варианты различались не только цветом.
- **Стадии:** 1 → 2 → 3, только растут, никогда не понижаются. Стадия считается по очкам роста (см. экономику).
- **Показатели** 0–100, обратимые:

| Показатель | Растёт от | Падает |
| --- | --- | --- |
| 🍗 Сытость | еда (нужное) | на фиксированную величину каждый период |
| 🧼 Уход | шампунь, расчёска, пластырь (нужное) | на фиксированную величину каждый период |
| 😊 Настроение | желаемое, подарки соседям, задания, подработки | немного каждый период; при невыполненном нужном |

- **Реакции:** радость, спокойствие, лёгкая грусть или вялость. Никаких болезней, травм, ухода из дома. Любое снижение обратимо в следующем периоде.
- **Тап по коту** — карточка: показатели и одна фраза «почему он сейчас такой».
- **Одежда и аксессуары** надеваются в гардеробе, поднимают только настроение.
- **Достигнутые цели** появляются в комнате кота.

## 4. Игровой период

Реального времени в игре нет: период закрывается кнопкой.

### 4.1. Начало периода

Экран «Новый период» с источником каждого начисления:

```
Карманные от мамы-кошки   +60
Осталось с прошлого раза  +25
Доступно на период         85
```

Здесь же события по сценарию: день рождения соседа, ответный подарок-предмет, непредвиденный расход (только «посложнее»).

### 4.2. План

- Три конверта: 🍗 Нужное · 🎈 Желаемое · 🐷 Копилка. Суммы кнопками «+5 / −5», без клавиатуры и процентов.
- Сверху «Не разложено: N». Больше доступного разложить нельзя — «+» неактивен, рядом пояснение.
- Нераспределённый остаток разрешён и переходит дальше.
- Подсказка у «Нужного»: «Коту на период нужно: еда 30 + уход 20 = 50».
- Совет соседей по желанию: тап по аватару — одна фраза. Не подсвечивается как верный.
- «Подтвердить план» → окно «Потом план не изменить, но тратить можно по-своему».

### 4.3. Внутри периода — в любом порядке

**Кошелёк один, конверты мягкие.** План — это намерение. Тратить можно из общего баланса, в том числе больше плана; расхождение видно на итоге.

**Заработок внутри периода** (задания и подработки) сразу приходит в кошелёк, его можно тратить, но в план текущего периода он не входит. На итоге — отдельной строкой; остаток переходит в «доступно» следующего периода.

**Магазин** — разделы «Нужное», «Желаемое», «Подарки» (открыт только во время события).

Карточка товара: цена · категория (значок + слово) · влияние на кота («🍗 Сытость +40») · напоминание о плане («По плану на желаемое осталось 10, это стоит 25 — план разойдётся с фактом») · кнопки «Купить» и «Хочу потом».

- Покупка требует подтверждения и попадает в историю периода.
- Отмены и возврата покупок нет. Путь восстановления — список «Хочу потом».
- **Не хватает денег** — окно «Не хватает 15» и варианты: выполнить задание или подработку, выбрать дешевле, «Хочу потом», взять из копилки (с отдельным подтверждением).

**Подарки** — события, не конверт. «У Шустрика день рождения!» → 2–3 подарка фиксированной цены, покупка идёт в желаемое. Сосед радуется, настроение кота растёт. Можно не дарить: «Спасибо, что поздравил!» — это не ошибка. Позже сосед сам дарит предмет по сценарию, не монеты и не случайно.

**Копилка**

- Выбор одной из 3 целей из мира кота: короткая, средняя, длинная.
- Экран цели: стоимость, накоплено, осталось, срок по средней сумме пополнений («если откладывать по 30 — через 2 периода»).
- «Положить» — перевод из баланса.
- «Взять» — отдельное подтверждение с предпросмотром: «Было 60, станет 40. Срок: 2 периода → 3».
- Цель достигнута — праздник, предмет в комнате, выбор следующей цели.

**Задания** (учебные, ядро игры)

- Ситуация 2–3 предложения, иногда реплика соседа → 2–3 действия, ни одно не помечено верным.
- Последствие в числах → объяснение для любого исхода → награда в монетах за прохождение → путь восстановления при неудаче.
- Открываются по 2 за период и не исчезают. В демо — все сразу.
- Темы: планирование бюджета, формирование сбережений, платежи и покупки; четвёртая — мошенники (после трёх обязательных).

**Подработки** (мини-игры на навык)

- «Касса» — посчитать сдачу; «Ценник-детектив» — где дешевле; «Хватит или нет» — прикинуть до покупки.
- Повторяются каждый период, лимит 2 за период, фиксированная оплата за прохождение, не за счёт.
- Короткое объяснение после игры независимо от результата.
- Пока мини-игры не готовы — временная подработка «помочь по дому» одним нажатием с той же оплатой.

### 4.4. Обратная связь после каждого финансового действия

Одна общая панель снизу — покупка, пополнение, снятие, награда, подарок:

```
Баланс: 115 → 90  (−25)
Копилка: 60 (без изменений)
😊 Настроение +20 — «Мурзик рад новому мячику»
[Понятно]
```

### 4.5. Завершить период

Подтверждение. Если нужное не куплено — мягкое предупреждение «Мурзик ещё не ел в этот период. Всё равно завершить?». Завершить можно всё равно.

### 4.6. Итог периода

- План и факт по трём конвертам в монетах: «Желаемое: план 20, потрачено 35 — на 15 больше».
- Отдельно: «Заработал за период: 50».
- Очки роста 0–3, каждое с причиной ✓ / ✗.
- Кот: как изменилось состояние и почему; «ещё 2 очка до стадии 2»; при смене стадии — анимация роста.
- Путь восстановления вместо оценки: «В следующий раз можно положить на желаемое побольше».
- «Следующий период».

## 5. Соседи и мошенник

| Где | Что происходит |
| --- | --- |
| План | Совет двух соседей по желанию, по одной фразе |
| Задания | Соседи — действующие лица, характеры постоянные |
| События | День рождения соседа, ответный подарок-предмет |
| Задания, тема 4 | Незнакомый кот-мошенник: «удвою монеты», «покажи копилку» |

Торопливый и Осторожный ошибаются одинаково часто, но по-разному. Верный выбор зависит от ситуации, а не от персонажа. Никакой насмешки.

## 6. Прогресс (📈 в верхней панели)

- Стадия кота и шкала очков; следующая стадия — силуэтом.
- Пройденные задания по темам.
- Текущая цель и достигнутые цели.
- Итог последнего периода и история периодов.
- Словарь: бюджет, план, факт, доход, расход, нужное, желаемое, накопления, цель, мошенник — по одной фразе. «Рубли Котляндии — игровые деньги, в магазине на них ничего не купить».

## 7. Настройки (⚙)

Звук вкл/выкл · анимации вкл/выкл · изменить внешность кота · подсказки · словарь · «Для взрослых».

## 8. Раздел взрослого

**Вход:** «Для взрослых» в настройках и на стартовом экране (чтобы эксперт мог попасть в демо, не проходя онбординг).

**Барьер:** пример «двузначное × однозначное» с вводом ответа цифровой клавиатурой, например «47 × 6 = ?». Каждый раз новый. Ошибка — просто новый пример, без блокировок. Обоснование: ребёнок 7–11 лет в уме его не решит быстро, взрослый — за секунды; ТЗ приводит арифметический пример как образец.

**Внутри:**

- Цели приложения: какие навыки тренирует игра.
- Пройденные темы: три обязательные и мошенники.
- Общий прогресс: периоды, стадия, достигнутые цели. Без оценок ребёнка.
- Сменить сложность (со сбросом, с подтверждением).
- Сбросить профиль / удалить профиль — с подтверждением.
- Демо-режим: запустить, сбросить.
- О приложении и лицензии. Внешние ссылки есть только здесь.

При выходе раздел закрывается, следующий вход — снова через барьер.

## 9. Демо-режим

- Запускается из раздела взрослого, работает на отдельном демо-профиле.
- Начинается с онбординга, чтобы показать шаги 1–3 Приложения А. Можно пропустить создание: «Готовый кот».
- Все задания открыты сразу. Финансовые правила — как в обычном режиме.
- **«Ускорить»** — прогон следующих периодов по сценарию «разумная игра» через тот же движок, итог каждого периода мелькает на экране. Гарантированно доводит до стадии 3.
- **«Сбросить демо»** — к исходному состоянию.
- Показ 9 вариантов: «Изменить внешность кота» на любом этапе.

Сценарий защиты: шаги 1–8 вручную → «Завершить период» → итог → ещё период вручную (смена стадии 1 → 2) → «Ускорить» до стадии 3 → закрыть и открыть приложение → раздел взрослого → сброс.

## 10. Что в каком порядке

1. **Обязательный минимум (к 29.09):** всё выше, кроме пунктов ниже; подработка — временная «помочь по дому».
2. **Затем:** мини-игры-подработки, соседи в заданиях и советы, подарки-события.
3. **Затем:** мошенники (тема 4), гардероб.
4. **К финалу:** бесконечная прогрессия после стадии 3 — новые цели и предметы для комнаты.
