# CashPet · Функционал и пользовательский путь

2026-09-24 · Версия 2: решения от 24.09 и тексты из [дорожной карты Ярика](05-дорожная-карта-контента.md). Источник решений — раздел 22 [рамок](../requirements/ЛЦТ-2026-задача-6-рамки-проекта.md). Числа — в [экономике](02-экономика.md).

Игра прежде всего про навыки: учебные задания по темам ТЗ — ядро, остальное (кот, магазин, копилка) показывает последствия решений.

**Слова в игре:** период — **неделя**, валюта — **монеты**, три части плана — **Нужно · Хочу · Отложить**.

## Карта экранов

```
Старт ─┬─ [Играть] ─► Онбординг (экраны 1–7 + сложность) ─► Задание «Первый день» ─► Дом
       └─ [Для взрослых] ─► барьер ─► Раздел взрослого (в т.ч. «Запустить демо»)

                 ┌───────────────── ДОМ (экран с котом) ─────────────────┐
 Верхняя панель: │ ⚙  │ 🪙 баланс │ 🐷 копилка · цель · полоска │ 📈 прогресс │
 Центр:          │           кот + 🍗 Сытость · 🧼 Уход · 😊 Настроение    │
 Над меню:       │           [Задание: …] — быстрый переход               │
 Нижнее меню:    │   Дом · План · Магазин · Копилка · Задания             │
                 └────────────────────────────────────────────────────────┘
 Кнопка «Завершить неделю» ─► подтверждение ─► Итог недели ─► Новая неделя ─► План
```

Шесть обязательных элементов главного экрана по п. 2.5.3: кот, баланс, накопления, текущая цель, показатели состояния, активное задание. Все видны без прокрутки при ширине 360 dp.

**Все разделы открыты с первой минуты.** Замков нет. При первом открытии раздела — 2–3 пузырька-подсказки (тексты из карты Ярика, разделы VII и IX), потом «?» в шапке открывает их снова.

## 1. Первый запуск

| Экран | Что происходит |
| --- | --- |
| Старт | «Играть» и неприметная ссылка «Для взрослых» |
| 1. Знакомство | «Привет! Для начала придумай имя для игры, не обязательно настоящее». Одно поле |
| 2. У тебя будет питомец | «Добро пожаловать в Котляндию!» Кнопка «Помогу!» |
| 3. Внешность | Сетка 3 × 3: 3 кота × 3 окраса, анимированные, стадия 1 |
| 4. Имя питомца | Поле с подсказкой «Например: Пончик», до 12 букв, проверка пустого и длинного |
| 5. Три вида решений | Нужно · Хочу · Отложить; мелко: «Монеты в игре игровые». Можно пропустить |
| 6. Как растёт питомец | Малыш → Подросток → Взрослый. Можно пропустить |
| 6а. Сложность | «Попроще / посложнее». К 29.09 меняет только допуск плана и подсказку «коту нужно 50». Сменить потом — в разделе взрослого со сбросом, после 29.09 |
| 7. Переход | «Всё готово! Сегодня первый день вместе». Кнопка «Начать» → задание «Первый день» |

Возраст, настоящее имя, контакты не спрашиваем. Кнопка «?» на каждом экране — возврат к подсказке в любой момент (п. 2.5.1).

## 2. Профили

- Один профиль ребёнка и отдельный демо-профиль: демо не трогает игру ребёнка.
- «Изменить внешность кота» в настройках: кот и окрас меняются в любой момент, прогресс сохраняется. Это «повторная настройка» из таблицы 2.6 ТЗ.
- Всё сохраняется автоматически после каждого действия (Room). Повторный запуск открывает ровно то же место.

## 3. Кот

- **Внешность:** 3 кота разного силуэта × 3 окраса. Окрас — цвет плюс узор, чтобы варианты различались не только цветом.
- **Стадии:** Малыш → Подросток → Взрослый. Только растут, никогда не понижаются.
- **Показатели** 0–100, старт 70, **никогда не ниже 25**:

| Показатель | Растёт от | В конце недели |
| --- | --- | --- |
| 🍗 Сытость | еда | × 0,75 |
| 🧼 Уход | шампунь, расчёска, полотенце, пластырь | × 0,8 |
| 😊 Настроение | желаемое, подарки соседям | × 0,7 |

- **Общее состояние** (0,4 · настроение + 0,3 · сытость + 0,3 · уход): радуется / спокоен / грустит. Никаких болезней, травм, ухода из дома; грусть снимается следующей покупкой.
- **Тап по коту** — карточка: показатели и одна фраза «почему сейчас так».
- **Аксессуары** поднимают только настроение. Гардероб, где их надевают, — после 29.09; до этого аксессуар — обычная покупка желаемого.
- **Достигнутые цели** появляются в комнате кота — после 29.09.

## 4. Неделя

### 4.1. Новая неделя

```
Карманные от мамы-кошки   +60
Осталось с прошлой недели +25
Доступно на неделю         85
```

В первую неделю вместо карманных — стартовый бюджет 100. После 29.09 здесь же появятся события: день рождения соседа, ответный подарок-предмет, непредвиденный расход (только «посложнее»).

### 4.2. План

- Три части: 🍗 Нужно · 🎈 Хочу · 🐷 Отложить. Кнопки «+5 / −5», без клавиатуры и процентов.
- Сверху «Не разложено: N». Больше доступного разложить нельзя — «+» неактивен, рядом пояснение. Нераспределённый остаток разрешён и переходит дальше.
- Подсказка у «Нужно»: «Коту на неделю нужно: корм 30 + шампунь 20 = 50».
- Совет соседей по желанию: тап по аватару — одна фраза, не подсвечивается как верная. К 29.09 — если останется время.
- «Подтвердить план» → «Потом план не изменить, но тратить можно по-своему». Кнопки «Подтвердить» / «Ещё подумаю».
- **После подтверждения** (п. 2.5.5 ТЗ) экран «План» показывает план и факт по ходу недели:

```
🍗 Нужно:    план 50 · потрачено 30 · осталось 20
🎈 Хочу:     план 25 · потрачено 35 · на 10 больше плана
🐷 Отложить: план 25 · отложено 10 · осталось 15
Заработано на неделе: 20 — в план не входит
```

  Превышение — значком и словами, не только цветом. «Отложено» = пополнения − снятия, покупка мечты не вычитается. Итог недели потом показывает то же сравнение целиком.

### 4.3. Внутри недели — в любом порядке

**Кошелёк один, части плана мягкие.** План — намерение; тратить можно из общего баланса, в том числе больше плана; расхождение видно на экране «План» и на итоге недели.

**Заработок внутри недели** (награды за задания и подработки) сразу приходит в кошелёк, тратить можно, но в план этой недели он не входит. На итоге — отдельной строкой.

**Магазин** — разделы «Нужное», «Желаемое»; после 29.09 — «Подарки», открыт только во время события. Каталог — в [экономике](02-экономика.md).

Карточка товара: цена · категория (значок + слово) · влияние на кота («🍗 Сытость +40») · напоминание о плане · кнопки «Купить» и «Хочу потом».

- **До подтверждения плана** вместо «Купить» — кнопка «Сначала план», она открывает экран плана. Магазин смотреть можно, покупать — после плана (ТЗ: план до расходов). То же в копилке: «Пополнить» до плана ведёт на план.
- Покупка требует подтверждения и попадает в историю недели. Отмены и возврата нет; путь восстановления — «Хочу потом».
- **Не хватает монет** — «Нужно {n} монет, а есть {m}. Что можно сделать?» Варианты: задание или подработка, что-то дешевле, «Хочу потом», взять из копилки (с отдельным подтверждением).

**Подарки** (после 29.09) — события, не часть плана. «У Рыжехвостика день рождения!» → подарки фиксированной цены, покупка идёт в «Хочу». Можно не дарить: «Спасибо за поздравление!» — это не ошибка. Позже сосед сам дарит предмет — по сценарию, не монеты и не случайно.

**Копилка** (экран по карте Ярика, раздел IX)

- Общий счётчик копилки. Копить можно и без цели — «про запас».
- Одна активная цель из трёх: Когтеточка 60, Домик 100, Велосипед 150. «Сменить мечту» — накопленное остаётся. Пока цели нет, в верхней панели: «Выбери мечту».
- Карточка цели: картинка, «накоплено {N} из {стоимость}», полоска из клеточек по 10, срок «примерно {n} недель» (по среднему «отложено за неделю», правило — в [экономике](02-экономика.md); пока откладывать нечего — не показываем).
- «Пополнить» — шаги +5 / +10 / +20. «Снять» — обязательный предпросмотр «было → станет»: сумма и срок, потом «Снять» / «Передумать».
- Накоплено достаточно — кнопка «Купить мечту» с подтверждением. Стоимость списывается из копилки, остаток сверх цены остаётся; панель «что изменилось»; праздник и выбор новой цели. Предмет в комнате кота — после 29.09. Правило — в [экономике](02-экономика.md), «Цели копилки».

**Задания** (учебные, ядро игры)

- Ситуация → 2–3 действия, ни одно не помечено верным → последствие в числах → разбор для любого выбора → награда в монетах за прохождение → при неудачном выборе кнопка «Попробовать иначе».
- **Правильность ответа ни на что не влияет:** ни на монеты, ни на рост кота. Монеты — за первое прохождение, фиксированные.
- Покупки внутри задания идут из **учебного кошелька задания** и не трогают настоящий баланс и план. На настоящий баланс идёт только награда — с панелью «что изменилось».
- Открываются по 2 новых в неделю и не исчезают. В демо — все сразу.
- **К 29.09 — 7 заданий на одном шаблоне «Выбор»:** 0 «Первый день», 1.1, 4.2 (покупки); 2.3 шаг 1, 6.2 (бюджет); 3.1 шаг 2, 3.3 (сбережения). Остальные задания карты и шаблоны (корзины, ползунок, чек-лист, смета) — после.
- Темы: планирование бюджета, сбережения, платежи и покупки; безопасность (мошенники) и праздники — после трёх обязательных.

**Подработки** (мини-игры на навык)

- «Касса» — посчитать сдачу; «Ценник-детектив» — где дешевле; «Хватит или нет» — прикинуть до покупки.
- Каждую неделю заново, лимит 2, оплата 10 за прохождение, не за счёт. Короткий разбор после игры.
- Пока мини-игры не готовы — временная подработка «помочь по дому» одним нажатием с той же оплатой.

### 4.4. Обратная связь после каждого финансового действия

Одна общая панель снизу — покупка, пополнение, снятие, покупка мечты, награда, подарок:

```
Баланс: 115 → 90  (−25)
Копилка: 60 (без изменений)
😊 Настроение +20 — «Пончик радуется новому мячику»
[Понятно]
```

### 4.5. Завершить неделю

Подтверждение. Если план не подтверждён — «Плана на эту неделю нет. Составим?» с кнопками «К плану» и «Завершить так»; без плана иконка «План удался» не загорается. Если нужное не куплено — мягкое предупреждение «На этой неделе Пончик пока без еды. Всё равно завершить?». Завершить можно всё равно.

### 4.6. Итог недели

- План и факт по трём частям в монетах: «Хочу: план 20, потрачено 35 — на 15 больше».
- «Заработано за неделю: 50».
- Три иконки: «Нужное в порядке», «План удался», «Копилка растёт» — горят полностью, наполовину или не горят; к каждой одна фраза «почему».
- Полоска «до следующей стадии». При смене стадии — праздник «Ура! Пончик теперь Подросток!» и причина из самой сильной иконки.
- Путь восстановления вместо оценки: «На следующей неделе можно положить в „Хочу“ побольше».
- «Следующая неделя».

## 5. Соседи и мошенники

Постоянные соседи: **Торопливый**, **Осторожный**, **Рыжехвостик** (именинник), **Длинноус**. Новых персонажей без решения команды не добавляем.

| Где | Что происходит |
| --- | --- |
| План | Совет Торопливого и Осторожного по желанию, по одной фразе |
| Задания | Соседи — действующие лица, характеры постоянные |
| События | День рождения Рыжехвостика, ответный подарок-предмет |
| Задания модуля 7 (после 29.09) | Мошенники без постоянного облика: окошко, звонок, сообщение. Исход всегда фиксированный |

Торопливый и Осторожный бывают правы по очереди; верный выбор зависит от ситуации, а не от персонажа.

## 6. Прогресс (📈 в верхней панели)

- Стадия кота и полоска ΣGP; следующая стадия — силуэтом.
- Пройденные задания по темам.
- Текущая цель и достигнутые цели.
- Итог последней недели и история недель.
- Словарь — из `glossary.json`.

## 7. Настройки (⚙)

Звук · анимации · изменить внешность кота · подсказки · словарь · «Для взрослых».

## 8. Раздел взрослого

**Вход:** «Для взрослых» в настройках и на стартовом экране.

**Барьер:** пример «двузначное × однозначное» с вводом ответа, например «47 × 6 = ?». Каждый раз новый, ошибка — просто новый пример.

**Внутри:** цели приложения · пройденные темы · общий прогресс без оценок ребёнка · сменить сложность (со сбросом, после 29.09) · сбросить / удалить профиль с подтверждением · демо-режим · о приложении и лицензии (внешние ссылки только здесь). При выходе раздел закрывается.

## 9. Демо-режим

- Запускается из раздела взрослого, работает на отдельном демо-профиле.
- Начинается с онбординга (шаги 1–3 Приложения А); экраны 5–6 пропускаются кнопкой.
- Все задания открыты сразу, финансовые правила — как в обычной игре.
- **«Ускорить»** — прогон следующих недель по сценарию «разумная игра» через тот же движок; итог каждой недели мелькает на экране. Стадия 3 — на 4-й неделе.
- **«Сбросить демо»** — к исходному состоянию.

Сценарий защиты: онбординг → «Первый день» → план → задание → покупки (нужное, желаемое, попытка при нехватке) → копилка → «Завершить неделю» → итог → ещё неделя вручную (Малыш → Подросток) → «Ускорить» до Взрослого → закрыть и открыть приложение → раздел взрослого → сброс.

## 10. Порядок работ

1. **К 29.09:** всё выше; задания — 7 на шаблоне «Выбор»; подработка — временная «помочь по дому».
2. **Затем:** мини-игры-подработки, остальные шаблоны и задания модулей 1–5, подарки-события.
3. **Затем:** модули 6–8 (заработок, безопасность, праздники), гардероб.
4. **К финалу:** звёзды знаний и статусы, рост цен со стадией, 4-я стадия и бесконечная прогрессия.
