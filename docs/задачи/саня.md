## ✅ Можно сейчас

1. **Написать в чат статус графики:** что готово из пробы «один кот × 3 стадии по частям» (срок был 21.09). От этого зависит, успеваем ли кота 3 × 3 к 29.09.
2. **Учебный проект в Android Studio** — New Project → Empty Activity. Верстать там экраны на фейковых данных по полям `UiState` из [контрактов](../08-контракты.md), раздел 8: Дом, План, Магазин, Копилка, Задание, Итог недели. Composable-функции потом переносятся в `app` почти без изменений.
3. **Общая панель обратной связи** («Баланс 115 → 90…») — один компонент на все действия, `FeedbackUi` в контрактах.
4. **Макеты в Figma** на 360 dp, если нужны тебе самому для вёрстки.
5. **Тема:** цвета, шрифт (Nunito, OFL), размеры — кнопки от 48 dp, текст от 16 sp.
