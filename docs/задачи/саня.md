# Саня · задачи

Обновлено: 2026-09-25.

> **Главное:** движок, контент, хранение и ViewModel настроек уже готовы — дело за экранами. Экспертам на сдаче нужны APK с настоящими экранами и минимум три из них: создание питомца, главный, бюджет или копилка. Напиши в чат 25.09 утром, что готово по графике и экранам и что мешает. Если не успеваешь — скажи сразу: Виталик или Леха возьмут часть экранов.

## 🧭 Где что лежит

Код и контент под экраны готовы: движок, хранение, загрузка контента, классы данных для каждого экрана и примеры для превью. Осталось сделать сами экраны.

**1. Прочитать сначала — 20–30 минут**

| Файл | Зачем |
| --- | --- |
| [01-функционал](../01-функционал.md) | Все экраны: что на каждом и какие кнопки. Главное для тебя |
| [08-контракты](../08-контракты.md), раздел 8 | Какие данные получает каждый экран |

| [CLAUDE.md](../../CLAUDE.md) | Правила: кнопки от 48 dp, текст от 16 sp, цвет никогда не единственный признак, анимации и звук отключаются |

**2. Код для экранов** — `app/src/main/kotlin/io/github/chalexey/cashpet/app/`

| Файл | Что там |
| --- | --- |
| `vm/UiState.kt` | **Данные для каждого экрана:** `HomeUiState`, `PlanUiState`, `ShopUiState`, `SavingsUiState`, `TasksUiState`, `TaskPlayUiState`, `WeekSummaryUiState`, `OnboardingUiState` и другие. **Свои классы для этого не объявляй — бери эти** |
| `vm/PreviewSamples.kt` | Готовые данные для `@Preview`: `PreviewSamples.home`, `.plan`, `.shop`, `.savings`, `.taskPlay`, `.weekSummary`, `.onboardingLook` и другие — числа уже правдоподобные |
| `vm/SettingsViewModel.kt` | Настройки (звук, анимации) — уже работают: `viewModel(factory = SettingsViewModel.Factory)` |
| `vm/AdultGateViewModel.kt` | Барьер раздела взрослого «47 × 6 = ?» — тоже работает |
| `MainActivity.kt` | Сейчас пустышка; отсюда начнётся навигация |

ViewModel остальных экранов делает Виталик — когда они появятся, экраны на `UiState` заработают с настоящими данными без переделок.

**3. Контент** — `content/src/main/resources/content/`

| Файл | Зачем тебе |
| --- | --- |
| `pet.json` | **`id` котов и окрасов: `fluffy`, `smooth`, `lop` и `ginger`, `grey`, `black`.** Файлы графики называются по ним. Если в графике другие имена — скажи сразу |
| `onboarding.json` | Тексты экранов знакомства и создания питомца |
| `shop.json`, `goals.json` | Товары и цели — какие картинки предметов нужны |
| `tasks.json`, `texts.json` | Тексты заданий и панели «что изменилось» — берутся отсюда, в код их не пишем |

Надписи интерфейса («Купить», «Сначала план», «Завершить неделю») — в `app/src/main/res/values/strings.xml`.

**4. Графика** — правила в [03-план](../03-план.md), раздел «Графика: требования»

- Имена: `cat_<кот>_s<стадия>_<часть>.svg`, например `cat_fluffy_s2_tail.svg`.
- Исходники — в `design/`, готовые векторы — в `app/src/main/res/drawable/`.
- Каждую ИИ-генерацию — в `design/ai-log.md`: требование ТЗ. Ассеты с лицензией — в `design/licenses.md`.

**5. Процесс:** ветка `sanya/что-делаешь` → перед push `git pull origin main` → PR. Файлы только в `app/`, `design/`, `docs/` — одобрит бот.

## ✅ Можно сейчас

0. **Готовые ViewModel можно подключать уже сейчас:** `SettingsViewModel` (звук, анимации) и `AdultGateViewModel` (барьер «a × b = ?»), описание — в PR #11 Виталика. ViewModel остальных экранов Виталик делает следующими.

1. **Открыть проект** в Android Studio: File → Open → папка `CashPet`, Run ▶ на телефоне. Должен открыться экран «CashPet · Заданий в контенте: 7».
2. **Написать в чат статус графики:** что готово из пробы «один кот × 3 стадии по частям». От этого зависит, успеваем ли кота 3 × 3 к 29.09.
3. **Экраны прямо в `app`** — ветка `sanya/screens`, пакет — `io.github.chalexey.cashpet.ui` или `...app.ui`, как в контрактах, **выбери с Виталиком, пока нет ни одного экрана**: тема, нижнее меню, верхняя панель, затем Дом, План, Магазин, Копилка, Задание, Итог недели. Данные — классы `UiState` из `app/src/main/kotlin/.../app/vm/UiState.kt` (Виталик положил их по разделу 8 [контрактов](../08-контракты.md)). **Свои `data class` для состояний не объявляй** — бери эти; для `@Preview` — готовые примеры `PreviewSamples.home`, `.plan`, `.shop` и т. д. Когда появятся ViewModel, экраны получат настоящие данные без переделок.
4. **Общая панель обратной связи** («Баланс 115 → 90…») — один компонент на все действия, `FeedbackUi`.
5. **До плана** в Магазине вместо «Купить» — кнопка «Сначала план», в Копилке «Пополнить» ведёт на план (`planConfirmed` в `UiState`). Тупиков быть не должно.
6. **Тема:** цвета, шрифт Nunito (OFL), кнопки от 48 dp, текст от 16 sp, цвет никогда не единственный носитель смысла.
