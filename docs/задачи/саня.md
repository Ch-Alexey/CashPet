## ✅ Можно сейчас

0. **Готовые ViewModel можно подключать уже сейчас:** `SettingsViewModel` (звук, анимации) и `AdultGateViewModel` (барьер «a × b = ?»), описание — в PR #11 Виталика. ViewModel остальных экранов Виталик делает следующими.

1. **Принять приглашение в репозиторий** на GitHub (письмо или github.com → уведомления). Без этого не получится пушить.
2. **Открыть проект** в Android Studio: File → Open → папка `CashPet`, Run ▶ на телефоне. Должен открыться экран «CashPet · Заданий в контенте: 26».
3. **Написать в чат статус графики:** что готово из пробы «один кот × 3 стадии по частям». От этого зависит, успеваем ли кота 3 × 3 к 29.09.
4. **Экраны прямо в `app`** — ветка `sanya/screens`, пакет `io.github.chalexey.cashpet.ui`: тема, нижнее меню, верхняя панель, затем Дом, План, Магазин, Копилка, Задание, Итог недели. Данные — фейковые, по полям `UiState` из [контрактов](../08-контракты.md), раздел 8: объяви эти `data class` у себя в `ui` с `@Preview`, Виталик потом подставит настоящие.
5. **Общая панель обратной связи** («Баланс 115 → 90…») — один компонент на все действия, `FeedbackUi`.
6. **До плана** в Магазине вместо «Купить» — кнопка «Сначала план», в Копилке «Пополнить» ведёт на план (`planConfirmed` в `UiState`). Тупиков быть не должно.
7. **Тема:** цвета, шрифт Nunito (OFL), кнопки от 48 dp, текст от 16 sp, цвет никогда не единственный носитель смысла.
