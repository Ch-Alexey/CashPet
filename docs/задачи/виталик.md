## ✔ Сделано

- `AdultViewModel` — раздел взрослого: прогресс открытого профиля без оценок (задания по темам, недели, стадия, мечты), «Сбросить профиль» и «Удалить профиль»; в демо — демо-профиль, так шаг 12 Приложения А проходит здесь. Стартовый экран видит удаление профиля — PR #31.
- `DemoViewModel` — демо-режим: «Запустить демо» (профиль или онбординг в демо), «Ускорить» до Взрослого с итогом каждой недели — ровно как те же решения вручную, «Сбросить демо», «Выйти из демо». Незакрытое демо переживает перезапуск: `settings.demo_active`, база версии 2 с миграцией и тестом — PR #29.
- `ShopViewModel` — витрина, «Сначала план», покупка, «Хочу потом», отказ с вариантами и «взять из копилки» одной панелью. `TasksViewModel` — открытые и пройденные задания, подработка «Помочь по дому». `TaskPlayViewModel` — задание через `TaskSession`: учебный кошелёк, «Попробовать иначе», диалог заглушки, награда на баланс. `WeekSummaryViewModel` — план и факт, иконки, стадия, кот, путь восстановления из нового `texts.json → week_hints` — PR #28.
- `PlanViewModel` — план недели: +5 / −5, «не разложено», подсказка «коту нужно 50» по сложности, советы соседей, черновик переживает перезапуск, после подтверждения — план и факт. `SavingsViewModel` — копилка: выбор мечты, пополнение, снятие с предпросмотром «было → станет», «Купить мечту», «Уже есть»; после действия — панель «что изменилось» или причина отказа — PR #27.
- `HomeViewModel` — главный экран: кот, показатели, фраза «почему сейчас так», баланс, копилка и цель, активное задание; «Завершить неделю» с предупреждениями «плана нет» и «нужное не куплено». `StartViewModel` — открыть сохранённый профиль, «Играть» → Дом или онбординг.
