## Как читать

- **✅ Можно сейчас** — ни от кого не зависит, начинай.
- **⏳ Нельзя пока** — написано, чего ждём и от кого. Когда блокер снят, пункт переезжает в «Можно сейчас».
- **✔ Сделано** — проверено Лехой; ссылка на коммит.
